# Stroke

Stroke is a simple whiteboard app for sketching ideas, doodling, and explaining concepts visually

## Features

Stroke currently supports:

- Freehand drawing with smooth strokes  
- Shape tools including rectangles, circles, ellipses, and diamonds  
- Arrows for connecting ideas  
- Text labels anywhere on the canvas  
- Custom colors, stroke widths, and fills  
- Precision erasing  
- Keyboard shortcuts for faster workflow  
- Dark mode for comfortable viewing  
- Undo and redo support  
- Optional grid with snap for alignment  

## Planned Improvements

Real-time collaboration is the main feature planned for the future. The goal is to allow multiple users to work on the same canvas and see updates live.

## Getting Started

To run the project locally:

    git clone https://github.com/Spaceboy-ren/Stroke.git
    cd stroke
    npm install
    npm run dev

## Tech Stack

- React with TypeScript  
- Vite  
- Zustand for state management  
- Tailwind CSS for styling  
- Framer Motion for animations  
- Lucide React for icons  

## Why the Name Stroke

Every drawing begins with a single stroke. The name reflects simplicity and focus.
